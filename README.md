# EchoNest

EchoNest 是 Discord AI 角色聊天與養成機器人，支援私人訊息與伺服器角色、好感度、等級、送禮、探索、任務、收藏及角色圖片。介面以繁體中文為主。

> 本專案仍需使用自己的 Discord、Gemini、Supabase 與圖片服務憑證完成部署及整合測試。功能可能受第三方服務可用性影響。

## 開始使用

1. 在 Bot 私人訊息或已安裝 EchoNest 的伺服器使用 `/建立角色`。
2. 使用 `/角色列表` 查看角色，並用 `/切換角色` 指定目前互動對象。
3. 在 DM 可直接輸入文字；在伺服器必須使用 `/聊天`。
4. 使用 `/角色狀態` 查看心情、等級、經驗值及個人好感度。

DM、不同伺服器之間的角色與玩家資料相互獨立。同一伺服器的成員可以與該伺服器角色互動，但只有建立者能編輯或刪除角色。

## 建立與管理角色

預設性格包含：傲嬌、毒舌、活潑、冷淡、溫柔、天然呆、腹黑、成熟。自訂性格使用 Discord 表單，描述需至少 100 字。

`/角色設定` 與 `/刪除角色` 僅限建立者操作。刪除會移除角色的相關養成資料、記憶及角色專屬進度；已發送到 Discord 的歷史訊息不會跟著刪除。角色建立者離開伺服器時，其在該伺服器建立的角色也會被清除。

## 聊天與記憶

角色依照性格、心情、近期對話、長期摘要與重要記憶生成回覆。每個角色使用最近 20 則聊天訊息；較早的訊息會逐步整理為摘要。重要記憶容量有限，並不保證記住所有對話。

**伺服器角色的記憶由同一伺服器的所有玩家共用。** 角色可能在與其他成員對話時提及你說過的內容。DM 記憶與伺服器記憶完全分開。

為避免刷取獎勵及過度使用 API，聊天設有冷卻、長度、每日額度與排隊限制。

## 養成與背包

- **好感度**：每位玩家與角色分別計算。
- **心情**：0～100，建立時為 70；伺服器角色的心情為共用數值。
- **EXP 與等級**：互動累積經驗值；伺服器角色共同養成。
- **背包**：各 DM／伺服器獨立保存物品。

## 簽到與送禮

使用 `/簽到` 領取每日花束，每個範圍每天一次，台灣時間午夜重置。使用 `/背包` 查看物品，再用 `/送禮` 將物品送給角色。送禮會消耗背包數量並增加好感度。

## 探索任務與收藏

使用 `/探索` 開始探索，依照指示選擇路線，完成後可獲得物品及探索紀念。使用 `/任務` 查看任務，完成條件後手動領取獎勵；同一獎勵不可重複領取。`/收藏` 可以查看已解鎖的收藏。

## 主動發言

僅限 DM，預設關閉。使用 `/聊天設定` 啟用，並選擇頻率：

| 頻率 | 每日目標範圍 |
|---|---|
| 偶爾 | 1～2 次 |
| 一般 | 3～5 次 |
| 活躍 | 6～10 次 |

發言時間為隨機安排，**不保證每日達到目標次數**。預設安靜時間為台灣時間 23:00～08:00，可透過指令設定。若最近 10 分鐘內聊過天，角色不會立即主動傳訊；連續未回覆可能降低好感度及心情，超過 7 天沒有 DM 聊天則暫停主動發言。

## 角色圖片

使用 `/生成角色圖片` 產生預覽。只有建立者可以確認更新。圖片功能需要管理者已設定相容的圖片生成服務；若未設定，指令會告知目前無法使用。

## 常見問題

**伺服器直接輸入文字為什麼沒有回覆？** 伺服器聊天需使用 `/聊天`；DM 才支援直接傳送文字。

**為什麼不能編輯角色？** 只有建立者可以修改或刪除角色。

**為什麼沒有增加 EXP？** 可能尚在聊天獎勵冷卻期間，或已達當日上限。

**角色為什麼沒有主動傳訊？** 請確認 DM 主動發言已開啟，且不在安靜時間；排程並非固定或保證發送。

**刪除後可以復原嗎？** 不行。請在確認刪除前再次檢查。

## 隱私與注意事項

- 不要在伺服器角色聊天中提供密碼、驗證碼、聯絡方式或其他不希望其他成員知道的資訊。
- AI 回覆可能有誤，不能當作可靠的專業資訊。
- 已發送到 Discord 的歷史訊息不會因角色刪除而自動消失。
- 使用量與圖片功能會受到第三方服務額度及管理者設定影響。
