# EchoNest

Discord AI 角色聊天與養成機器人。支援 DM 和伺服器角色、Gemini 聊天、角色心情、好感度、簽到、背包、送禮、探索、任務及收藏。

> 目前為可部署的核心功能實作，不是全部規劃功能的完成版。尚未完成主動發言排程、完整長期記憶整理、AI 圖片生成、互動式多回合探索、完整禮物庫及防刷獎勵機制。未完成的功能不會假裝成功執行。

## 開始使用

1. 將 EchoNest 加入伺服器，或開啟與 Bot 的私人訊息。
2. 使用 `/建立角色` 建立角色。
3. 使用 `/角色列表` 查看角色，或 `/切換角色` 切換角色。
4. 使用 `/聊天` 開始聊天；DM 也支援直接輸入訊息。
5. 使用 `/簽到`、`/探索`、`/背包`、`/送禮` 體驗基本養成。

## 私人訊息與伺服器

- DM 的角色、背包和進度與伺服器互相獨立。
- 每個伺服器有自己的角色和進度。
- 伺服器角色由建立者管理，其他成員可以與角色聊天。
- 同一伺服器角色共用聊天歷史，請勿分享密碼、驗證碼或私密資訊。
- 伺服器只透過 `/聊天` 回應；不會監聽一般頻道聊天。

## 角色與養成

- 預設性格：傲嬌、毒舌、活潑、冷淡、溫柔、天然呆、腹黑、成熟。
- 可自訂角色性格描述。
- 每個玩家與角色的好感度分開計算；角色心情與 EXP 共用。
- 簽到以台灣時間每日重置。
- 刪除角色不可復原，並移除相關聊天與養成資料。

## 注意事項

- 目前聊天獎勵尚未實作完整冷卻與每日限制，正式開放前應補齊。
- 圖片生成與主動訊息排程尚未完成。
