# EchoNest

Discord AI 角色聊天與養成機器人。使用 Gemini 聊天、Agnes AI 生圖、Pillow 角色卡、Supabase 儲存資料與圖片。

## 開始使用

將機器人加入 Discord 伺服器，或開啟私人訊息。使用 `/建立角色` 建立角色，再使用 `/聊天` 開始對話。私人訊息與伺服器的角色和背包分開儲存。

## 角色指令

| 指令 | 功能 |
| --- | --- |
| `/建立角色` | 建立角色，選擇預設或自訂性格 |
| `/角色列表` | 查看角色 |
| `/切換角色` | 切換對話角色 |
| `/角色設定` | 透過按鈕編輯名稱、性格與圖片 |
| `/刪除角色` | 建立者永久刪除角色 |
| `/角色狀態` | 顯示心情、好感度、等級、EXP 與角色圖片卡片 |
| `/上傳角色圖片` | 上傳角色圖片 |

## 聊天與記憶

| 指令 | 功能 |
| --- | --- |
| `/聊天` | 與選取角色聊天 |
| `/聊天設定` | 設定 DM 主動發言頻率 |
| `/記住` | 建立者新增角色重要記憶 |
| `/記憶列表` | 建立者查看重要記憶 |
| `/刪除記憶` | 建立者刪除重要記憶 |

角色可參考近期聊天紀錄、簡要歷史與最多三則相關重要記憶。伺服器角色共享聊天紀錄，請勿在聊天中透露個人敏感資料。

## 養成與收藏

| 指令 | 功能 |
| --- | --- |
| `/背包` | 查看持有的物品 |
| `/簽到` | 每日領取花束 |
| `/送禮` | 輸入背包內的禮物名稱送給角色 |
| `/探索` | 每日最多五次，隨機取得物品 |
| `/任務` | 領取每日探索任務獎勵 |
| `/收藏` | 查看收藏紀錄 |

禮物池有 62 種物品。好感度依使用者分開計算，角色心情與等級共用。

## 圖片生成

`/生成角色圖片` 會依角色設定及外觀描述呼叫 Agnes AI，先顯示預覽。只有建立者按下「使用這張圖片」，才會將圖片儲存到 Supabase Storage 並更新角色狀態卡；取消不會覆蓋原圖。生成請求可能使用服務額度。

## 使用須知

- Bot 必須持續在線才能回覆或發送主動訊息；免費 Web Service 可能休眠。
- 圖片生成需要服務可用且設定 API 金鑰，沒有完成真實帳號端到端測試。
- 長期記憶摘要目前是簡化整理，並非完整的 AI 自動摘要系統。
- 主動發言適用單實例運作；多實例部署需要額外排程鎖。
- 管理員部署說明請參閱 `build.txt`。
