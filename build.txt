EchoNest 開發與部署說明
======================

1. 使用 Python 3.12。安裝：pip install -r requirements.txt
2. 複製 .env.example 為 .env，填入 DISCORD_TOKEN、DATABASE_URL、GEMINI_API_KEY。
3. 在 Supabase 新專案 SQL Editor 執行 database/schema.sql。
4. 已有資料庫時，請先備份並人工比較資料表差異，不要直接刪表。
   本版需要 characters.image_url、chat_settings.unanswered、explorations、important_memories。
   如既有資料庫是上一份 EchoNest schema，備份後可檢查並執行 database/upgrade_existing.sql。
5. Supabase Storage 建立 public bucket，名稱 character-images（或調整環境變數）。
   圖片由伺服器使用 service_role key 上傳，絕對不要放到前端或 GitHub。
6. 圖片 API：IMAGE_API_URL、IMAGE_API_KEY、IMAGE_MODEL。
   目前圖片介面是通用 JSON 格式：POST {model,prompt}，Bearer 認證，
   預期回傳 data[0].url / images[0].url 或 base64。
   Agnes AI 的真實端點、請求及回應格式尚未驗證；需依官方文件調整 images.py。
   如使用其他服務商，須檢查圖片來源網域允許清單。
7. Discord Developer Portal：開啟 Server Members Intent，邀請時授權 bot 與 applications.commands。
   需 Send Messages、Embed Links、Attach Files 權限。普通訊息不會觸發聊天。
8. 本機啟動：python bot.py。測試：python -m unittest discover -s tests
9. Docker：docker compose up --build
10. Render：Web Service / Docker。Health Check Path 設為 /health。
    Render 自動提供 PORT；程式監聽 0.0.0.0。若免費方案休眠，Discord 連線也會中斷。
11. 檢查 Logs：HTTP health server started、Database verified and Discord commands synchronized、Gateway connected。
12. 驗收：建立角色、切換角色、聊天、狀態卡、圖片上傳、簽到、探索、任務、送禮、刪除角色。
13. 先在 Render 設定 IMAGE_API_KEY、IMAGE_API_URL、IMAGE_MODEL 與 SUPABASE_URL、SUPABASE_SERVICE_ROLE_KEY。
    IMAGE_API_URL=https://apihub.agnes-ai.com/v1/images/generations
    IMAGE_MODEL=agnes-image-2.1-flash
    Supabase Storage 需建立公開 character-images bucket。
14. 如果資料庫報 tenant/user not found，請重新複製目前 Supabase 專案的 Session Pooler URI。
15. 不要同時啟動多個使用相同 Token 的機器人實例；排程與任務目前不具備跨實例去重保證。

目前限制
========
- Agnes AI 介面尚未取得官方規格，無法保證圖片生成可直接使用。
- 記憶摘要為截斷式歷史整理，非 LLM 產生的高品質長期摘要。
- 重要記憶表已建立及可檢索，但沒有自動擷取的重要記憶寫入流程。
- 探索是每日限次的隨機掉落，未實作多回合事件。
- 禮物池目前 62 項。
- 主動訊息為單實例週期掃描，沒有跨實例鎖與排程持久化保證。
- 圖片生成提供確認與取消按鈕；按鈕逾時後需重新生成。
